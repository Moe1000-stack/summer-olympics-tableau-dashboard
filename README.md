# Summer Olympics Historical Dashboard

An interactive Tableau dashboard exploring historical Summer Olympics data from 1896 onward.

## Dashboard Highlights

- Top 10 countries by total Olympic medals
- Medal breakdown by Gold, Silver, and Bronze
- Medal distribution across Olympic disciplines
- Historical medal trends over time
- Summer Olympics filtering and interactive dashboard actions

## Tools & Technologies

- Tableau
- Tableau Public
- CSV
- Data Visualization
- Data Analysis

## Data

The project uses historical Olympic datasets, including:
- `olympic_medals.csv`
- `olympic_hosts.csv`

The datasets were related using the `Slug Game` and `Game Slug` fields.

## Dashboard

The dashboard combines multiple visualizations into an interactive view designed to make historical Olympic performance easy to explore.

### Visualizations
1. Top 10 Countries by Medals
2. Medals by Discipline
3. Summer Olympic Medals Over Time
